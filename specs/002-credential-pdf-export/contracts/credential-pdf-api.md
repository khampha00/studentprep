# API Contracts: Printable Student Credential PDF Export (Slice 002)

These contracts extend Section **1.3 (Role Separation)** and Section **2.5 (Student Identity & Onboarding)** in [docs/api_contract.md](file:///c:/Users/User/Desktop/studentprep/docs/api_contract.md).

## 1. Consolidated Bulk Student Credential Roster PDF (All Registered Students)

- **Endpoint**: `GET /api/v1/admin/students/credentials/pdf`
- **Authorization**: `ROLE_ADMIN` only (`ROLE_SUPERVISOR`, `ROLE_STUDENT` -> `403 Forbidden`; missing/expired token -> `401 Unauthorized`). Audited via `AuditLogAspect`.
- **Success Response (`200 OK`)**:
  - **Headers**:
    - `Content-Type: application/pdf`
    - `Content-Disposition: form-data; name="attachment"; filename="student_credentials_roster.pdf"` (or standard attachment filename `"student_credentials_roster.pdf"`)
    - `Cache-Control: no-store`
  - **Body**: Multi-page A4 PDF binary generated by OpenPDF containing:
    - Title banner (`StudentPrep Examination Credential Roster`), generation timestamp, scope (`All Registered Students`), and total candidate count.
    - Repeating header table columns across all pages: `#`, `Candidate Name`, `Registration Number`, `Login PIN`.
    - Clean empty-state notice (`"No registered students found."`) when 0 matching students exist.
- **Behavior**:
  - Reuses existing encrypted PINs without rotating or interrupting active exam sessions.
  - Auto-provisions initial 5-digit PINs once for any legacy/unissued candidate (`pinResetRequired = true` or `pinCiphertext == null`).
- **Error Responses (RFC 7807 `ProblemDetail`)**:
  - `401 Unauthorized`: missing/expired/evicted JWT.
  - `403 Forbidden`: caller is not `ROLE_ADMIN`.
  - `500 Internal Server Error`: stored `pinCiphertext` cannot be decrypted under active key (`"Unable to decrypt stored student PIN. Check CREDENTIAL_ENCRYPTION_KEY or reset affected student PINs."`) or PDF rendering I/O failure.

## 2. Batch Student Credential Roster PDF (CSV Cohort / Specific Candidates)

- **Endpoint**: `POST /api/v1/admin/students/credentials/pdf`
- **Authorization**: `ROLE_ADMIN` only. Audited via `AuditLogAspect`.
- **Request Body (`application/json`)**:
  ```json
  {
    "registrationNumbers": [
      "JAMB-2026-AB12CD",
      "JAMB-2026-EF34GH"
    ]
  }
  ```
- **Validation**:
  - `registrationNumbers` MUST be non-empty (`@NotEmpty`) and capped at a safe maximum (`@Size(min = 1, max = 5000)`), with each item non-blank. Invalid input returns RFC 7807 `400 Bad Request`.
- **Success Response (`200 OK`)**:
  - **Headers**:
    - `Content-Type: application/pdf`
    - `Content-Disposition: form-data; name="attachment"; filename="batch_credentials_roster.pdf"`
    - `Cache-Control: no-store`
  - **Body**: Authoritative OpenPDF roster generated strictly from PostgreSQL records matching `registrationNumbers` (client never supplies PIN values).

## 3. Single-Student Credential Slip PDF (Updated Existing Endpoint)

- **Endpoint**: `GET /api/v1/admin/students/{id}/slip`
- **Authorization**: `ROLE_ADMIN` only (audited via `AuditLogAspect`).
- **Success Response (`200 OK`)**:
  - **Headers**:
    - `Content-Type: application/pdf`
    - `Content-Disposition: form-data; name="attachment"; filename="slip.pdf"` (downloaded client-side as `${registrationNumber}-slip.pdf`)
    - `Cache-Control: no-store`
  - **Body**: Printable single-student PDF slip containing:
    - `Candidate Name`
    - `Registration Number`
    - `Login PIN: <5-digit PIN>` *(replacing the redacted Slice 001 notice)*
    - `Registered Subjects`
- **Behavior**:
  - Preserves the existing encrypted PIN across repeat downloads.
  - If the student lacks a retrievable PIN (`pinResetRequired = true` or `pinCiphertext == null`), issues and persists a fresh 5-digit PIN once and prints it.
- **Error Responses**:
  - `404 Not Found` (mapped via `NoSuchElementException`): student UUID does not exist.
  - `401 Unauthorized` / `403 Forbidden` / `500 Internal Server Error` (matching bulk endpoint rules).

## 4. Unchanged Privacy Guarantees
- `GET /api/v1/admin/students` and `GET /api/v1/admin/students/{id}` (`StudentResponse`) continue returning `id`, `name`, `registrationNumber`, `pinResetRequired`, `hasActiveSession`, and `subjects` with **zero PIN or ciphertext fields**.
- `GET /api/v1/admin/students/export` continues returning sanitized CSV (`Name,Registration Number,Registered Subjects`) with **zero PIN columns**.
- `POST /api/v1/admin/students` and `POST /api/v1/admin/students/{id}/reset-pin` continue returning the 5-digit PIN immediately as before and now also persist its encrypted copy for future PDF downloads.
